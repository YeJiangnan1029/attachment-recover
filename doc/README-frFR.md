# attachment_recover

`attachment_recover` est un plugin Zotero 7 pour recuperer des pieces jointes PDF manquantes entre plusieurs appareils.

L'etat actuel du depot :

- initialisation du projet plugin
- verification de build
- entree de menu `Tools -> Attachment Recover`
- page de preferences provisoire

Voir `project_requirements.md` pour les exigences detaillees.
