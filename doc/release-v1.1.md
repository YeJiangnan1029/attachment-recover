# attachment_recover v1.1

## 概要

`v1.1` 实现了第一个可用的 PDF 附件恢复完整流程，包括描述符生成、扫描恢复、以及当前条目的状态面板。

## 新增功能

- 当前条目状态面板：在右侧面板显示文件名、恢复状态、来源、最后更新时间、报错信息
- 四种直观状态：`已下载`、`缺失`、`下载中`、`恢复失败`
- 项目自定义 SVG 图标和状态高亮样式

# attachment_recover v1.1 (English)

## Summary

`v1.1` delivers the first usable recovery workflow for missing PDF attachments in Zotero, with descriptor generation, scan-and-recover, and a current-item status panel.

## New Features

- Current-item status panel showing filename, state, source, last updated time, and error message
- Four visual recovery states: `Downloaded`, `Missing`, `Downloading`, `Recovery Failed`
- Custom SVG icon and highlighted state styles for the status panel
